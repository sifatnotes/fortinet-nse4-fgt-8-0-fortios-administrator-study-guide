## Exam Overview

The **Fortinet NSE 4 - FortiOS 8.0 Administrator (NSE4_FGT-8.0)** exam validates your technical competence in configuring, operating, and troubleshooting daily firewall operations, security policies, VPNs, and system settings on FortiGate devices running FortiOS 8.0.

| Parameter | Exam Specification |
| --- | --- |
| **Exam Code** | NSE4_FGT-8.0 |
| **Total Questions** | 60 (Multiple Choice & Drag-and-Drop) |
| **Time Allowed** | 60 minutes |
| **Passing Score** | ~70% (Scaled Score) |
| **Delivery Method** | Pearson VUE (Online Proctored via OnVUE or In-person Test Center) |
| **Validity** | 2 Years |

## Who Should Take It

This certification is designed for network security engineers, firewall administrators, systems engineers, and SOC analysts responsible for day-to-day administration and security enforcement using FortiGate security processing units.

**Recommended Prerequisites:**
- Knowledge of basic networking fundamentals (OSI model, TCP/IP, subnets, static/dynamic routing).
- 6+ months of hands-on experience administering FortiGate firewalls in enterprise environments.
- Completion of the FortiGate Security and FortiGate Infrastructure training tracks.
